# Changelog

Todas las notas de cambio relevantes de Despensa al Día.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el versionado
[Semantic Versioning](https://semver.org/lang/es/).

## [Unreleased]

### Changed

- Capturas del README movidas a PNG con logo JPG (render garantizado en GitHub).
- Botones de descarga directa del APK firmado en el README.

## [1.1.0] - 2026-09-15

### Added

- Nuevo tema `Despensa Pop`: modo claro, colorido e infantil (rosa, menta, amarillo y lavanda).

### Changed

- Encabezado de `Mi Inventario` rediseñado: título completo, iconos de acceso rápido sin recortes y mejor jerarquía.
- Capturas del README en formato vectorial y logo actualizado.

### Fixed

- Contraste corregido en la hero card de `Usa Primero` entre temas claro y Pop.

## [1.0.0] - 2026-09-15

### Added

- Primera release pública de Despensa al Día.
- Inventario offline-first con búsqueda, filtros, vencimientos, precios y stock mínimo.
- Pantalla `Usa Primero` para priorizar productos por urgencia.
- Lista de compras, planificador semanal, recetas, estadísticas y logros.
- Escáner de código de barras con búsqueda opcional en Open Food Facts.
- Notificaciones locales, widget y respaldo/importación JSON.
- APK release firmada publicada como artefacto de GitHub Release.

### Security

- La llave privada de firma no se versiona en el repositorio.
