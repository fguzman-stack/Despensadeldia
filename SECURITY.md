# Security Policy

## Supported Versions

The project is in active development. Security fixes target the default branch first.

## Reporting a Vulnerability

Please open a private security advisory on GitHub if available, or create an issue without including sensitive personal data.

Relevant issues include data loss, unintended network disclosure, unsafe backup/import handling, leaked secrets or dependency vulnerabilities.

## Privacy Baseline

The core inventory must work without accounts, ads, analytics, paid services or a project-owned server. Online integrations must remain optional and visible to the user.
